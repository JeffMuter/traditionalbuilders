# Builder Logo Permissions — HOLDING AREA (not served)

These logo files are **not** part of the website. This directory lives outside
`static/` and is therefore **not served** by the app. Nothing in `static/images/logos/`
remains — all logos were removed from the served tree.

## Why these are here

Each logo below comes from a firm whose site is **silent** on content reuse:
no terms-of-use page, no press/brand kit, no explicit reservation of rights.
Silence still means *all rights reserved* under copyright/trademark law, so we
**cannot display these yet**. They are retained only so we can attach/compare
them when we email each firm for permission after launch.

Firms that showed an **explicit "all rights reserved" or trademark claim**
(Vermont Frames, Mellows & Paladino, Jeff Johnson, Custom Timber Frames,
Hardwick, Pinneo, ART*, Goosewing*, …) were deleted outright — do not re-download
them without written permission. (*ART and Goosewing carry only a bare © notice
and were judged boundary-silent; see the ticket for the exact call.)

## Rules

- **Never** move these into `static/` until written permission is on file.
